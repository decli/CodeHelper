相对 v1.3.1 的关键改动
  • 新增首次启动引导（3 步，每步一个动作，可跳过），权限申请前先解释「为什么」。
  • 英雄区去卡片化：104sp 数字直接落纸面，节省一张卡高度；数字为 0 时变松绿。
  • 卡片只留一个主按钮「我已取到」（60dp 松绿）；看短信 / 复制 / 读给我听 降为 48dp 文字按钮。删去短信正文与识别依据。
  • 点取件码 → 全屏出示：最大 150sp、临时提亮、复制 / 播报 / 标记一步到位。
  • 读给我听：按字逐个朗读（「3 杠 3 杠 0 6 0 0 6」），真机接 TTS；此处调用浏览器语音。
  • 已取件降为一行摘要（松绿对勾 + 灰码 + 恢复），扫读时不与待取混淆。
  • 时间面板带件数预览，老人不必反复试档。
  • 设置自动保存，去掉「保存并刷新」；字号 / 外观 / 分组进设置；高级规则折叠，默认不打扰。
  • 所有文字 ≥15sp（次级）/ ≥17sp（正文），触控目标 ≥48dp；撤销条 6 秒内可一步恢复。
