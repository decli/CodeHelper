04 · UI / 视觉 / 交互规范 · v1.4

取件码助手 · 柿柿如意设计规范

面向 60 岁以上、在驿站柜台前单手举着手机的用户。规范只回答三个问题：能不能一眼看到码、能不能一下点对、点错了能不能改回来。所有令牌与 Color.kt / Type.kt 保持一一对应，仅新增 3 个字阶与 1 个字重。

柿橙 = 待办 / 主操作 松绿 = 完成 / 确认 暖纸 = 页面 · 纯白 = 卡片

规则：深色下取件码仍用 DarkInk #EFE8DB 而非橙色——码是内容不是状态；橙色只留给数字「N 个」与选中态。提示条在深色下反相（浅底深字），保证从深卡片中跳出。
用色三条
① 一屏最多一个柿橙实心块（选中态或主数字）+ 一个松绿实心块（主按钮）。
② 灰字（InkMuted）只用于时间、说明、已取件码；从不用于可点击文字——可点击文字一律 PersimmonDeep。
③ 不用半透明降低文字对比；需要弱化就换令牌。
禁止
· 左侧彩色竖条卡片、渐变背景、玻璃拟态
· 用红色表示「未取」——红色只给表单错误
· 图标单独承担含义（每个图标必须带文字）
· 对取件码使用任何非 900 字重或非等宽数字

05

交互规范

手势 · 每个手势都有按钮替身
点取件码全屏出示（替身：无需，即点即到）左滑卡片露出 132dp 抽屉「我已取到 / 恢复」；替身 = 卡内可见按钮双击卡片打开系统短信；替身 = 「看短信」下拉列表重新读取短信；替身 = 换时间范围自动刷新系统返回关闭浮层 → 返回首页；引导页第 1 步不可返回
不使用：长按、双指、横向翻页作为唯一路径。
状态 · 首页四态
未授权数字 0（松绿）+ 权限卡，「全部包裹」禁用；先说为什么再弹系统框读取中数字保留旧值，副标题「正在读取短信…」，列表位放加载卡；<300ms 不显示空待取空 = 「包裹都取完了」（松绿）；全部空 = 「这段时间没有取件码」（灰）；均给「看更早的短信」有数据待取按时间倒序、按驿站分组；已取件只在「全部」尾部出现
反馈 · 可逆优先
我已取到卡片 200ms 收起 → 数字减少 → 提示条带「撤销」6s；不弹确认框恢复立即恢复 + 提示条（无撤销）复制提示条「已复制 27017」+ 轻触振动读给我听图标脉冲；语速 0.75×，逐字读，连字符读「杠」；再点一次停止换时间范围面板关闭 → 加载 → 数字/列表同时更新，胶囊文字同步设置即改即存，页脚说明「不需要再点保存」；仅高级规则语法错误时红字阻止
动效 · 克制
入场浮层 / 卡片：上移 24dp + 淡入，250ms，ease-out切换分段 / 开关 / 颁色：200ms 底色过渡，不位移按下scale .98，80ms数字颜色 300ms 过渡；不做滚轮数字动画加载单环旋转 900ms；不做骨架屏闪烁减少动效系统开启时全部改为即时切换
