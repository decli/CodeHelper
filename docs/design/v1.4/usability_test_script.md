# 取件码助手 v1.4 · 老年用户 5 分钟任务测试脚本

**目的**：验证 1a 方案在真实老人手中能否「一眼找到码、一下点对、点错能改回」。
**对象**：5 位 60–80 岁、自己去过驿站取件、日常用智能手机的用户（至少 2 位 70+，至少 1 位习惯系统字号「大」）。
**设备**：测试机（6.9″，Android 16）预装原型/测试版；准备 4 条模拟短信（见附录 A）；测试环境尽量在明亮处（模拟驿站）。
**人员**：主持 1 人（只读脚本、不解释界面）、记录 1 人（计时 + 填表）。
**时长**：每人 5 分钟任务 + 3 分钟访谈。

---

## 0. 开场（30 秒，照读）
> 「您好，我们在做一个帮您从短信里找快递取件码的小程序。接下来我会请您用它做几件小事，就像您平时去驿站取快递一样。我不会教您怎么用，做不出来也完全没关系，那是我们设计得不好，不是您的问题。您做的时候可以随时把想法说出来。」

确认：口头同意录屏/录音（仅屏幕，不录脸）。

---

## 1. 任务（共 5 分钟，主持人计时，每题超时上限见括号）

记录员对每个任务填写：**完成 / 提示后完成 / 失败**、**用时**、**误触次数**、**原话**。

### T1 找码（60s）
主持人把手机（首页，3 个待取）递给用户：
> 「您现在到了菜鸟驿站柜台，工作人员问您取件码是多少。请您找出来，读给我听。」

✅ 成功：读出 `3-3-06006` 或 `8-5-06003`（任一即可）。
观察：是否第一眼看数字「3」还是看卡片；是否试图点数字；是否被「待取/全部」分段干扰。

### T2 放大出示（45s）
> 「工作人员说看不清，想让您把手机屏幕拿给他看。您能把取件码弄得更大一点吗？」

✅ 成功：点取件码进入全屏出示页。
观察：是否看到「点一下取件码可放大出示」提示；是否误点「我已取到」。若 30s 未完成给一次提示：「试试点一下那串数字」。

### T3 标记已取（30s）
> 「快递拿到手了。请您告诉这个程序，这个包裹已经取到了。」

✅ 成功：点绿色「我已取到」（出示页或卡片均可）。
观察：从出示页还是先返回；是否理解绿色按钮含义；是否寻找「确认」弹窗。

### T4 撤销 / 恢复（45s）
> 「哎呀，您刚才点错了，其实那个包裹还没拿到。请把它改回来。」

✅ 成功（任一）：6 秒内点提示条「撤销」；或 → 切到「全部包裹」→ 在「已取件」里点「恢复」。
观察：是否注意到底部提示条；提示条消失后能否找到「全部包裹」；「恢复」二字是否被理解。

### T5 换时间范围（45s）
> 「您想起来三天前还有一个快递没取，请找出三天前的那个取件码。」

✅ 成功：点「最近 12 小时」胶囊 → 选「最近 3 天」→ 读出 `B-2-1188`。
观察：胶囊是否被识别为可点；面板里「N 件待取」是否被用到；是否误点「全部包裹」。

### T6 读给我听（30s，可选，剩余时间做）
> 「您眼睛累了不想看，能让手机把取件码念出来吗？」

✅ 成功：点「读给我听」，并确认能听清（追问：「它念的是哪几个数字？」）。
观察：语速 0.75× 是否合适；「杠」是否被理解为「-」。

---

## 2. 访谈（3 分钟）
1. 「这几步里，哪一步您觉得最不顺手？」
2. 「屏幕上有没有哪个字您看不清、或者不知道是什么意思？」（指认）
3. 「绿色的大按钮您觉得是干什么的？橙色的数字呢？」
4. 「如果这个程序装在您手机上，您去驿站会用它吗？为什么？」
5. 系统字号设为「大」的用户追问：「刚才有没有字被挤掉或者叠在一起？」

## 4. 通过标准（5 人汇总）
| 指标 | 通过线 | 不通过时的默认修改 |
|---|---|---|
| T1 无提示完成率 | ≥ 5/5，中位用时 ≤ 10s | 提高卡头对比 / 减少首屏元素 |
| T2 无提示完成率 | ≥ 4/5 | 码区加浅色底或放大镜图标；或改为长按 → 不采用，改按钮 |
| T3 完成率 | 5/5，误点 0 | — |
| T4 完成率（任一路径） | ≥ 4/5；≥ 3/5 用提示条撤销 | 提示条延至 8s 或加振动；「全部包裹」改「含已取件」 |
| T5 无提示完成率 | ≥ 3/5 | 胶囊加「换时间」文字；或把时间档做成首页第二行 |
| T6 听清率 | ≥ 4/5 | 语速降至 0.65×；数字间停顿加长 |
| 系统大字号下无遮挡/重叠 | 0 例 | 修 layout（`softWrap=false` 处逐一检查） |
| 「绿色 = 完成、橙色 = 待办」语义正确理解 | ≥ 4/5 | 按钮文案加「✓」前缀或改为「拿到了」 |

任意一项不通过 → 修改后对 2 位新用户复测该任务。

## 附录 B · 主持人禁忌
- 不说「点这里」「你看那个绿色的」——只能重复任务原句，或用脚本里规定的唯一提示。
- 用户沉默 10 秒以上才可问「您现在在想什么？」。
- 不纠正读音，不评价对错；用户失败时说「好的，这个我们记下了，是我们的问题」。
