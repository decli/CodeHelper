# 取件码助手 · UI 设计规范 v1.4「柿柿如意」

> 状态：**已实现（v1.4.0）**。本文是工程侧的规范正本，与 `docs/design/v1.4/` 里的设计交付包一一对应。
> 交付包中 `04 设计规范.dc.html` 是可视化版本，`03 交互原型.dc.html` 是可点击原型，本文是可检索、可评审的文字版。
>
> 面向 60 岁以上、在驿站柜台前单手举着手机的用户。规范只回答三个问题：
> **能不能一眼看到码、能不能一下点对、点错了能不能改回来。**

## 0. 设计原则

| 原则 | 落地 |
| --- | --- |
| 一屏只答一个问题 | 首页第一眼只回答「还有几个包裹待取」，104sp 数字直接落在纸面上 |
| 一码一行，永不折行 | 取件码用 `TextMeasurer` 逐档实测字号，一个码一个单行 `Text` |
| 全应用一种选中语言 | 柿橙实心底 + 白色对勾；未选中用 2dp 描边，不靠颜色单独表意 |
| 每个手势都有按钮替身 | 左滑 ↔ 卡内按钮，双击 ↔「看短信」，下拉 ↔ 换时间范围 |
| 可逆优先 | 标记已取到 6 秒内可撤销，「全部包裹」里随时可恢复；不用确认弹窗打断 |

## 1. 色彩令牌

`Color.kt` 原值不变，语义映射在 `Theme.kt`。括号内为与常用底色的对比度。

| 用途 | 浅色 | 深色 | colorScheme 槽位 |
| --- | --- | --- | --- |
| 页面底 | `#F5F2EC` 暖纸 | `#17130D` | `background` |
| 卡片 | `#FFFFFF` | `#221C13` | `surface` |
| 正文 | `#221D15` 浓墨（15.4:1） | `#EFE8DB` | `onSurface` |
| 辅助字 | `#6E675A`（5.0:1） | `#A79C8A` | `onSurfaceVariant` |
| 撕票线 / 分隔 | `#ECE6DB` | `#3A3223` | `outlineVariant` |
| 未选中描边 | `#8A8171`（3.4:1） | `#5C523F` | `outline` |
| 柿橙 · 待办 / 选中 / 主数字 | `#D2400E`（白字 5.2:1） | `#FF8A50` | `primary` |
| 柿橙上文字 | `#FFFFFF` | `#3A1503` | `onPrimary` |
| 可点击文字 | `#A93307`（6.6:1） | `#FFB694` | `onPrimaryContainer` |
| 柿霜 · 胶囊底 | `#FBEADF` | `#3A2412` | `primaryContainer` |
| 未取件标签底 | `#FFE3D2` | `#3A2412` | `secondaryContainer` |
| 松绿 · 完成 / 主按钮 | `#1E7A3C`（白字 5.6:1） | `#6FC98A` | `tertiary` |
| 已取件底 | `#E4F3E8` | `#1C2E1F` | `tertiaryContainer` |
| 填充按钮底 | `#F5F2EC` | `#2E2718` | `surfaceVariant` |
| 提示条 | 底 `#322F2A` / 字 `#F5F2EC` | 底 `#EFE8DB` / 字 `#17130D` | `inverseSurface` / `inverseOnSurface` |

**用色三条**

1. 一屏最多一个柿橙实心块（选中态或主数字）+ 一个松绿实心块（主按钮）。
2. 灰字只用于时间、说明、已取件码；可点击文字一律 `onPrimaryContainer`。
3. 不用半透明降低文字对比；需要弱化就换令牌。唯一允许的 alpha 是时间面板选中行右侧的件数（85%，纯装饰）。

**禁止**：左侧彩色竖条卡片、渐变背景、玻璃拟态；用红色表示「未取」（红色只给表单错误）；图标单独承担含义；对取件码使用非 900 字重或非等宽数字。

深色模式下取件码仍用 `onSurface` 而不是橙色——码是内容不是状态；深色去阴影，改 1dp `outlineVariant` 描边；提示条反相为浅底深字。

## 2. 字阶（`Type.kt`）

> **v1.4.1 / v1.4.2 调整**：真机走查（6.9″ / 430dp，深色）后整体上调一档，正文字重 400 → 500，
> 取件码与首页大数字的字重回到 800（900 会被系统合成加粗，笔画糊、字面更宽，反而更难认）。
> 原因见 `docs/ui-redesign-v1.4.md` 2.5 / 2.6 两节。下表是当前值。

| 令牌 | 规格 | 用途 |
| --- | --- | --- |
| `HeroNumber` ★ | 104sp / 800 / tnum / -2sp | 首页待取数量，0 时转松绿 |
| `displayMedium` | 22–104sp / 800 / tnum | 取件码基准，按卡宽实测取最大值 |
| `displaySmall` ★ | 32sp / 800 | 引导页、全屏状态标题 |
| `headlineMedium` | 26sp / 800 | 面板标题、空状态标题、关于弹窗 |
| `headlineSmall` | 24sp / 800 | 加载态标题、出示页主按钮 |
| `ButtonLarge` ★ | 22sp / 700 | 60–68dp 主按钮 |
| `titleLarge` | 22sp / 700 / +0.5sp | 页面标题 |
| `titleMedium` | 20sp / 700 | 分段控件、设置项标题、面板选项 |
| `labelLarge` | 19sp / 600 | 文字按钮、胶囊、分组标题、卡头时间 |
| `bodyLarge` | 18sp / 500 | 正文最小字号，引导页描述用 20sp |
| `bodyMedium` / `Caption` | 16sp / 600 | 全应用最小字号，只用于非关键说明 |

★ = v1.4 新增。**已删除** `labelMedium` 14sp 与全部 12sp 用法（识别依据、supportingText）——低于适老底线。
正文一律 ≥500 字重：深色模式下 400 字重的细笔画会发虚，加粗一档比放大一号更管用。

**取件码自适应**：`AutoSizeCodeLines` 用 `TextMeasurer` 二分实测，常规范围 40–104sp；「特大」档上限 ×1.15（119sp）；出示页上限 150sp。一码一行，永不折行、不省略。

**字间距按码长分档**：≤5 位 +4sp，6–7 位 +2sp，≥8 位 +1sp。取件码是按宽度实测放大的，字间距每多 1sp，10 位的码就要少掉约 1.5sp 字号——字号比字间距更重要，长码优先让位给字号。

**码区宽度**：首页列表左右边距 16dp（不是通用的 20dp），卡片里码区左右内边距只留 4dp，出示页的码横向铺满整屏。这三处不是普通留白，而是直接决定取件码能放多大——凡是影响取件码尺寸的间距，一律字号优先。

**数字字重固定 800**：不要再提到 900。系统中文字体多数没有真实 900 字面，会触发合成加粗，笔画糊、字碗被填小、字面变宽（实测字号反而更小），深色模式下尤其明显。

## 3. 间距 · 圆角 · 层级

- **间距刻度**：4 / 8 / 12 / 16 / 20 / 28。页面左右 20dp，卡片间 16dp，卡内边 16–20dp，分组标题上方 4dp，列表底部留 120dp 给提示条。
- **圆角**：卡片 24 · 出示页/面板 28 · 分段外框 20 / 内段 16 · 主按钮 18–20 · 次级按钮 14–16 · 胶囊与标签 pill。
- **层级只有三层**：0 纸面 / 1 卡片（`shadowElevation 2dp`）/ 2 浮层（6dp + 40% 遮罩）。深色模式阴影归零，改 1dp 描边。
- **触控目标** ≥48dp，相邻目标间距 ≥8dp；主按钮 60dp，出示页主按钮 68dp。

## 4. 组件

**按钮三级**：主按钮 60dp / 20sp（完成类松绿、前进类柿橙，一屏一个）；填充按钮 56dp 暖纸底；文字按钮 48dp 行高、`onPrimaryContainer`、左图标 20dp。禁用 = 50% 透明且不可点，文字颜色不变。按下 scale .98 / 80ms。

**选中语言**：选中 = 柿橙实心 + 白对勾；多选芯片选中 = 柿橙浅底 + 对勾；未选中 = 2dp `outline` 描边。带下拉箭头的胶囊表示「点开可换」。

**取件卡（待取）**：卡头「发件方 · 时间」（左，灰）+ 未取件标签（右，10dp 柿橙圆点）；码区可点进入出示页，下方 caption「点一下取件码可放大出示」；撕票线把「看」与「做」分开；动作区 = 一个 60dp 松绿主按钮「我已取到」+ 三个 48dp 文字按钮「看短信 / 复制 / 读给我听」。**不显示短信正文，也不显示识别依据。**

**已取件行**：降为一行摘要——44dp 松绿圆形对勾 + 灰色码（28sp，不划线，划线影响识读）+「已取 · 驿站 · 时间」+「恢复」文字按钮。

**提示条**：17sp / 圆角 18 / 深底浅字；带撤销时停留 6s，纯提示 2.5s；撤销是 48dp 柿橙实心按钮而不是文字。

**空状态**：96dp 圆角 32 图标容器，图标 52dp；标题说结果，正文说下一步，按钮给出口；语义色跟状态（完成松绿、缺权限柿橙、无结果灰）。

## 5. 交互

**手势与替身**

| 手势 | 行为 | 按钮替身 |
| --- | --- | --- |
| 点取件码 | 全屏出示 | 即点即到，无需替身 |
| 左滑卡片 | 露出 132dp 抽屉 | 卡内「我已取到 / 恢复」按钮 |
| 双击卡片 | 打开系统短信 | 「看短信」按钮 |
| 系统返回 | 关闭浮层 → 回首页 | 引导页第 1 步不可返回 |

不把长按、双指、横向翻页作为唯一路径。

**首页四态**：未授权（数字 0 松绿 + 权限卡，「全部包裹」禁用）/ 读取中（数字保留旧值，副标题「正在读取短信…」，<300ms 不显示加载卡）/ 空（待取空 = 「包裹都取完了」松绿；全部空 = 「这段时间没有取件码」灰）/ 有数据（待取按时间倒序并按驿站分组，已取件只在「全部包裹」尾部）。

**反馈**：标记已取到 → 卡片收起 → 数字减少 → 6s 可撤销提示条，不弹确认框；复制 → 提示条 +轻触振动；读给我听 → 图标脉冲、语速 0.75×、逐字读、连字符读「杠」、再点一次停止；设置即改即存，页脚说明「不需要再点保存」。

**动效上限**：入场 250ms ease-out；底色切换 200ms；按下 scale .98 / 80ms；数字颜色 300ms。系统「减少动效」开启时全部改为即时切换。

## 6. 适老化 / 无障碍检查表（每次发版前逐项打钩）

| # | 检查项 | 依据 |
| --- | --- | --- |
| 1 | 所有文字 ≥15sp，正文 ≥17sp，可操作文字 ≥17sp；系统字号 1.3× 下无截断、无重叠 | 工信部适老化 · WCAG 1.4.4 |
| 2 | 文字对比 ≥4.5:1（大字 ≥3:1）；不用透明度弱化文字；深色同样达标 | WCAG 1.4.3 |
| 3 | 触控目标 ≥48×48dp，相邻间距 ≥8dp；主按钮 ≥60dp | WCAG 2.5.8 · M3 |
| 4 | 每个手势都有等价的可见按钮 | WCAG 2.5.1 |
| 5 | 状态不只靠颜色：选中带对勾、未选带描边、待取/已取带文字标签 | WCAG 1.4.1 |
| 6 | 状态性操作可撤销（6s 提示条）或可恢复，不用确认弹窗打断 | WCAG 3.3.4 |
| 7 | 图标一律配文字；contentDescription 完整（「放大出示取件码 27017」而非「按钮」） | WCAG 1.1.1 |
| 8 | 取件码逐字朗读，连字符读「杠」，不按整数读；TalkBack 与「读给我听」口径一致 | TTS 语义 |
| 9 | 取件码一码一行、永不折行、不省略；出示页强制不锁屏并临时提亮 | 场景需求 |
| 10 | 文案口语化，技术词（正则、规则 N）只出现在折叠的高级区 | WCAG 3.1.5 |
| 11 | 提示条自动消失前 ≥2.5s，含操作时 ≥6s；无自动轮播、无闪烁 | WCAG 2.2.1 |
| 12 | 尊重系统「减少动效」；焦点顺序 = 阅读顺序（数字 → 分段 → 卡 → 主按钮 → 次按钮） | WCAG 2.3.3 · 2.4.3 |
